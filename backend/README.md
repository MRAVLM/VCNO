# 🖥️ بک‌اند (Backend)

سرور پروژه: API، منطق کسب‌وکار و دیتابیس.

> این پوشه بخشی از **بخش کدها** در [`AGENTS.md`](../AGENTS.md) است.

---

## 🛠️ پشته‌ی پیشنهادی (تا تأیید نهایی)

| لایه | انتخاب | دلیل |
|---|---|---|
| زبان | **TypeScript** | مشترک با فرانت‌اند — فقط یک زبان یاد بگیر |
| سرور | **Node.js + Fastify** | سبک و سریع، مناسب تازه‌کارها |
| دیتابیس | **PostgreSQL + Prisma** | مدل‌سازی امن و ساده |
| تست | **Vitest** | هماهنگ با ابزارهای مدرن JS |

> ⚠️ این پشته «پیشنهاد» است و موقع scaffold کردن کد، با هم نهایی‌اش می‌کنیم.
> اگر ترجیح دیگری داری (مثلاً Python/FastAPI) بگو تا همین README را عوض کنیم.

---

## 📂 ساختار پیشنهادی

```
backend/
├── README.md
├── package.json
├── src/
│   ├── index.ts          ← نقطه‌ی ورود سرور
│   ├── routes/           ← مسیرهای API (فقط دریافت و پاسخ)
│   ├── services/         ← منطق کسب‌وکار (هیچ‌وقت داخل route مستقیم ننویس)
│   ├── db/               ← اتصال دیتابیس + مدل‌ها (Prisma)
│   └── utils/            ← توابع کمکی عمومی
└── tests/                ← تست‌ها کنار همین ساختار
```

**قاعده‌ی طلایی:** `route → service → db`
هر درخواست اول به `route` می‌رسد، منطق در `service` اجرا می‌شود و دسترسی به داده فقط در `db`.

## 🚀 دستورهای پرکاربرد (بعد از scaffold)

```bash
npm run dev        # اجرای محلی با hot-reload
npm run test       # اجرای تست‌ها
npm run typecheck  # بررسی تایپ‌ها
```
