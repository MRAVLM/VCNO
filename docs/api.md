# 🔌 مرجع API (API Reference)

> **برای چه کسی؟** کسی که با سرور کار می‌کند (فرانت‌اند یا هر مصرف‌کننده‌ی دیگر).
> **وضعیت:** ⚪ هنوز خالی است — بعد از نهایی‌شدن بک‌اند پر می‌شود.

## قالب مستندسازی هر endpoint

برای **هر** مسیر این قالب را رعایت کن:

```md
### `METHOD /path` — عنوان فارسی

- **چه زمانی استفاده می‌شود:** ...
- **دسترسی:** عمومی / نیازمند توکن
- **ورودی (Body/Params):**
  | فیلد | نوع | ضروری | توضیح |
- **خروجی موفق:** نمونه JSON
- **خطاهای محتمل:** `400` / `401` / `404` / ...
```

## نکته برای ایجنت‌ها

- هر endpoint جدید، **همان‌لحظه** به همین فایل اضافه شود.
- نمونه‌های JSON باید واقعی و از روی خروجی تست باشند، نه ساختگی.
