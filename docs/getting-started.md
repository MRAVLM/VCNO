# 🚀 شروع سریع (Getting Started)

> **برای چه کسی؟** کسی که تازه وارد پروژه شده و می‌خواهد در ۵ دقیقه پروژه را بالا بیاورد.
> **چه زمانی؟** اولین باری که پروژه را clone کردی.

## پیش‌نیازها

- [ ] نصب Node.js (نسخه‌ی ...)
- [ ] نصب Git
- _(بعد از نهایی‌شدن پشته، اینجا را کامل کن)_

## مراحل راه‌اندازی

```bash
# ۱) دریافت پروژه
git clone <آدرس-مخزن>
cd <نام-پروژه>

# ۲) نصب وابستگی‌ها
# (بعد از scaffold کامل می‌شود)

# ۳) اجرای پروژه
# npm run dev
```

## اولین نتیجه‌ی موفق

- [ ] سرور بک‌اند بالا آمد: `http://localhost:3000`
- [ ] صفحه‌ی فرانت‌اند باز شد: `http://localhost:5173`

## خطاهای رایج

| خطا | دلیل محتمل | راه‌حل |
|---|---|---|
| `command not found: npm` | Node.js نصب نیست | نصب Node.js از سایت رسمی |
| | | |
