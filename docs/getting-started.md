# 🚀 شروع سریع (Getting Started)

> **برای چه کسی؟** کسی که تازه وارد پروژه شده و می‌خواهد در چند دقیقه بفهمد چطور با این مخزن کار کند.
> **چه زمانی؟** اولین باری که پروژه را clone کردی.

## چرا این سند مهم است

VCNO یک اپلیکیشن اجرایی نیست — یک **سیستم مهارت (skill) برای ایجنت‌های کدنویس** است.
پس «راه‌اندازی» یعنی: مخزن را بگیر، به ایجنت بگو چه کاری انجام دهد، و مطمئن شو اعتبارسنجی‌ها سبزند.

## پیش‌نیازها

- [ ] **Git** — برای clone کردن
- [ ] **یک ایجنت کدنویس** — یکی از این‌ها کافی است (نیازی به همه نیست):
  Claude Code · Cursor · GitHub Copilot · Codex · Gemini CLI · Windsurf
- [ ] **Python 3** (اختیاری) — فقط برای اجرای محلی اسکریپت اعتبارسنجی

> ⚠️ **وضعیت واقعی کد:** هنوز `package.json`‌ای در مخزن نیست؛ یعنی `npm run dev` / `npm run test`
> فعلاً **وجود ندارد** و نباید ادعای اجرایشان را داشت. (پشته‌ی پیشنهادی در
> [`../backend/README.md`](../backend/README.md) و [`../frontend/README.md`](../frontend/README.md) است.)

## مراحل راه‌اندازی

```bash
# ۱) دریافت پروژه
git clone https://github.com/MRAVLM/VCNO.git
cd VCNO

# ۲) نقطه‌ی ورود را باز کن
#    AGENTS.md ← همه‌چیز این‌جاست (اسکیل‌ها، داکس، قواعد)
```

۳) **به ایجنت بگو از کدام اسکیل استفاده کند** — فقط نام دستور کافی است:

```text
/init     ← پروژه را بفهم و context را بنویس (اولین قدم همیشه این است)
/check    ← نیازمندی‌ها را اعتبارسنجی کن
/PRD      ← طرح بنویس
/Build    ← پیاده‌سازی کن
/Feedback ← بازخورد را اعمال کن  (↺)
/Doc      ← مستندات را نهایی کن
```

جزئیات هر دستور داخل خودش است: [`../skills/`](../skills/README.md)

## اولین نتیجه‌ی موفق

- [ ] `git clone` بدون خطا انجام شد
- [ ] ایجنت فایل [`../AGENTS.md`](../AGENTS.md) را خواند
- [ ] با دستور `/init`، فایل `docs/project.md` ساخته شد
- [ ] گیت‌هاب‌اکشن `validate` در تب Actions سبز است (روی هر push اجرا می‌شود)

## اعتبارسنجی محلی (همان چیزی که CI اجرا می‌کند)

```bash
python3 scripts/validate.py
```

- فرانت‌متر همه‌ی `SKILL.md` ها (نام kebab-case، منطبق با پوشه، توضیح غیرخالی)
- همه‌ی لینک‌های نسبی مارک‌داون

## خطاهای رایج

| خطا | دلیل محتمل | راه‌حل |
|---|---|---|
| `command not found: git` | Git نصب نیست | نصب از [git-scm.com](https://git-scm.com/) |
| `could not resolve host` | اتصال اینترنت/پروکسی | بررسی شبکه و تنظیمات پروکسی |
| `broken relative link` در CI | لینک داکس به فایل غایب | اصلاح لینک یا ساخت فایل مقصد |
| `frontmatter ... is not kebab-case` | نام اسکیل انگلیسی/kebab نیست | اصلاح `name:` در `SKILL.md` |
| ایجنت دستور `/init` را نمی‌شناسد | مسیر اسکیل را نخوانده | بگو `skills/init/SKILL.md` را بخواند |
