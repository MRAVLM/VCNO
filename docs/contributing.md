# 🤝 راهنمای مشارکت (Contributing)

> **برای چه کسی؟** هرکسی که می‌خواهد به پروژه کمک کند — انسان یا ایجنت.
> **وضعیت:** ⚪ در حال تکمیل.

## چرخه‌ی کار (Workflow)

1. یکی از داکس‌ها یا اسکیل‌های نیمه‌کاره را از فهرست‌ها انتخاب کن.
2. اول داکس/الگو را ویرایش کن، بعد کد (اگر لازم بود).
3. قبل از پایان: `npm run typecheck` و `npm run test`.
4. پیام کامیت: انگلیسی، کوتاه، توضیح‌دهنده.

## چه چیزی را نباید بدون هماهنگی عوض کرد؟

- پشته‌ی فنی (backend/frontend README)
- ساختار `AGENTS.md`
- قالب `skills/_template/SKILL.md`

## اضافه‌کردن اسکیل جدید

از [`../skills/README.md`](../skills/README.md) پیروی کن — الگو آماده است.
