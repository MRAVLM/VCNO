# 🤝 راهنمای مشارکت (Contributing)

> **برای چه کسی؟** هرکسی که می‌خواهد به پروژه کمک کند — انسان یا ایجنت.
> **چه زمانی؟** قبل از اولین commit یا pull request.

## چرا این سند مهم است

این مخزن با AI ساخته می‌شود؛ بدون قواعد مشترک، ایجنت‌ها موازی کار می‌کنند و
داکس از کد عقب می‌ماند. این صفحه کمترین قواعد لازم برای هم‌جهت‌ماندن است.

## چرخه‌ی کار (Workflow)

1. **ایشو باز کن** قبل از هر تغییر بزرگ (تغییر گردش‌کار، پشته، ساختار).
2. اول **داکس/اسکیل** را به‌روز کن، بعد کد (اگر کدی وجود داشت).
3. قبل از پایان، اعتبارسنجی را اجرا کن (پایین) و نتیجه‌ی واقعی را گزارش بده.
4. پیام کامیت: **انگلیسی، فعل‌محور، با scope** — `feat(vcno): ...`، `docs: ...`، `fix(ci): ...`.

## اعتبارسنجی اجباری (قبل از هر push)

```bash
python3 scripts/validate.py
```

- **فرانت‌متر** هر `SKILL.md` (نام kebab-case، منطبق با پوشه‌اش، توضیح غیرخالی)
- **لینک‌های نسبی** همه‌ی مارک‌داون‌ها (لینک شکسته = CI قرمز)

این دقیقاً همان چیزی است که گیت‌هاب‌اکشن روی **هر push** اجرا می‌کند:
[`.github/workflows/validate.yml`](../.github/workflows/validate.yml)

> وقتی هسته‌ی کد scaffold شد، `npm run typecheck` و `npm run test` هم اجباری می‌شوند
> (طبق [`conventions.md`](conventions.md)) — فعلاً `package.json`‌ای وجود ندارد.

## اضافه‌کردن اسکیل جدید

1. کپی از الگو:
   ```bash
   cp -r skills/_template skills/<نام-انگلیسی-kebab>
   ```
2. `name:` را **دقیقاً** با نام پوشه یکی کن (انگلیسی و kebab-case) و `description` را کامل بنویس.
3. در [`../skills/README.md`](../skills/README.md) ثبتش کن.
4. اگر ایجنت‌ها به شیم نیاز دارند، `.claude/skills/<نام>/SKILL.md` را هم بساز (فقط اشاره کند، کپی نکند).
5. `python3 scripts/validate.py` باید سبز باشد.

## چه چیزی را نباید بدون هماهنگی عوض کرد؟

- پشته‌ی فنی (`../backend/README.md` و `../frontend/README.md`)
- ساختار [`../AGENTS.md`](../AGENTS.md)
- قالب [`_template/SKILL.md`](../skills/_template/SKILL.md)
- محتوای شیم‌ها (CLAUDE.md, GEMINI.md, ...) — آن‌ها فقط pointer هستند

## قواعد داکس

- **فارسی برای توضیح، انگلیسی برای نام فایل‌ها و کد.**
- یک داکس = یک مخاطب؛ کوتاه و عملی؛ هر تغییر بزرگ اول در داکس.
- جدول‌های وضعیت (`✅/🟡/⚪`) را با واقعیت هم‌گام نگه دار —
  داکس باید **واقعیت** را بگوید، نه نقشه را (اصل `/Doc`).
