# 🏗️ معماری پروژه (Architecture)

> **برای چه کسی؟** هرکسی که می‌خواهد قبل از نوشتن کد، **تصویر کلی** پروژه را ببیند.
> **چه زمانی؟** قبل از هر تغییر بزرگ.

## تصویر کلی

```
کاربر
  │
  ▼
┌──────────────┐     HTTP/JSON     ┌──────────────┐      ┌──────────────┐
│   frontend/  │ ────────────────▶ │   backend/   │ ───▶ │   Database   │
│  (React UI)  │ ◀──────────────── │  (Fastify)   │      │ (PostgreSQL) │
└──────────────┘                   └──────────────┘      └──────────────┘
```

## جریان یک درخواست

1. کاربر در فرانت‌اند عملی انجام می‌دهد.
2. کلاینت در `frontend/src/api/` درخواست می‌زند.
3. بک‌اند در `routes/` دریافت می‌کند → `services/` منطق را اجرا → `db/` داده را می‌خواند.
4. پاسخ JSON برمی‌گردد و UI به‌روز می‌شود.
