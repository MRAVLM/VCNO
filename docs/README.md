## ✍️ الگوی نوشتن هر داکس

هر فایل داکس باید این ساختار را داشته باشد:

```md
# عنوان
> یک خط: این سند برای چه کسی و چه زمانی لازم است؟

## چرا این سند مهم است
## مراحل / محتوای اصلی
## خطاهای رایج
## پیوند به داکس‌های مرتبط
```

**قواعد:**
1. **یک داکس = یک مخاطب.** سعی نکن همه‌چیز را برای همه بنویسی.
2. **کوتاه و عملی.** هر بخش باید قابل اجرا باشد، نه فقط توضیح نظری.
3. **تازه نگه‌داشتن.** هر تغییر بزرگ در کد، اول باید در داکس دیده شود.
4. **فارسی برای توضیح، انگلیسی برای کد و نام فایل‌ها.**
