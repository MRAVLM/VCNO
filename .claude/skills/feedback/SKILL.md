# اسکیل `/Feedback` — نسخه‌ی ورودی Claude Code

> این فایل یک **shim** است تا Claude Code اسکیل را در مسیر بومی خودش (`.claude/skills/`) پیدا کند.
> منبع واحد حقیقت: [`skills/feedback/SKILL.md`](../../../skills/feedback/SKILL.md)

**آن فایل را بخوان و دقیقاً طبق همان مراحل اجرا کن.** خلاصه‌ی سریع:

- مأموریت: «کاربر دقیقاً چه را می‌خواهد عوض شود، چرا، و چطور بدون شکستن بقیه‌ی پروژه؟»
- قبل از هر تغییر: classify (نوع/شدت/دامنه) → Expected vs Actual → ریشه‌یابی → کوچک‌ترین تغییر ایمن → تست → verify.
- آیتم‌ها را با `FB-NNN` و وضعیت ردیابی کن؛ بازخورد مهم را هرگز دور نریز (`DEFERRED`/`REJECTED` با دلیل).
- تغییر major محصول → بازگشت به `/check → /PRD → /Build`؛ وصله‌ی علامت، حدسِ ابهامِ مادی، ادعای `VERIFIED` بدون verification، loop بی‌پایان ممنوع.
- خروجی: `# VCNO Feedback Report`. حلقه: بازخوردِ جدیدِ بعدی دوباره همین‌جاست.
