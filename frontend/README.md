# 🎨 فرانت‌اند (Frontend)

رابط کاربری پروژه: صفحات، کامپوننت‌ها و ارتباط با بک‌اند.

> این پوشه بخشی از **بخش کدها** در [`AGENTS.md`](../AGENTS.md) است.

---

## 🛠️ پشته‌ی پیشنهادی (تا تأیید نهایی)

| لایه | انتخاب | دلیل |
|---|---|---|
| زبان | **TypeScript** | مشترک با بک‌اند |
| فریم‌ورک | **React + Vite** | محبوب‌ترین انتخاب، منبع آموزشی فراوان |
| استایل | **Tailwind CSS** | سریع و بدون دردسر CSS جداگانه |
| حالت داده | **TanStack Query** | مدیریت تماس با API و کش |

> ⚠️ این پشته «پیشنهاد» است و موقع scaffold کردن کد، با هم نهایی‌اش می‌کنیم.

---

## 📂 ساختار پیشنهادی

```
frontend/
├── README.md
├── package.json
└── src/
    ├── main.tsx          ← نقطه‌ی ورود برنامه
    ├── app/              ← مسیرها و چیدمان کلی (Router)
    ├── components/       ← کامپوننت‌های قابل استفاده‌ی مجدد
    ├── pages/            ← هر صفحه یک فایل
    ├── api/              ← کلاینت تماس با بک‌اند (فقط اینجا fetch بزن)
    └── styles/           ← استایل‌های سراسری
```

**قاعده‌ی طلایی:** `page → component → api`
صفحه چیدمان می‌دهد، کامپوننت کار UI را می‌کند و تماس با سرور فقط از `api/` انجام می‌شود.

---

## 🚀 دستورهای پرکاربرد (بعد از scaffold)

```bash
npm run dev        # اجرای محلی با hot-reload
npm run test       # اجرای تست‌ها
npm run typecheck  # بررسی تایپ‌ها
npm run build      # ساخت نسخه‌ی نهایی
```
