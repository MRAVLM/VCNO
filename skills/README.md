# 🧩 بخش اسکیل‌ها (Skills)

اسکیل یعنی **«دستور آماده‌ی تکرارپذیر برای ایجنت»**.
به‌جای اینکه هر بار یک پرامپت بلند بنویسی و مسیر کار را توضیح بدهی، یک‌بار اسکیل را می‌سازی و بعد فقط می‌گویی: *«فلان اسکیل را اجرا کن»*.

> **چه کسی از این بخش استفاده می‌کند؟** تازه‌کاری که نمی‌داند پرامپت چیست — کافی است فهرست زیر را ببیند و نام اسکیل را به ایجنت بدهد.

---

## 📂 ساختار

```
skills/
├── README.md              ← همین فایل (فهرست + راهنما)
├── _template/
│   └── SKILL.md           ← الگوی خالی برای ساخت اسکیل جدید
├── init/SKILL.md         ← /init     (مرحله ۱ — درک)
├── check/SKILL.md        ← /check    (مرحله ۲ — اعتبارسنجی)
├── prd/SKILL.md          ← /PRD      (مرحله ۳ — برنامه‌ریزی)
├── build/SKILL.md        ← /Build    (مرحله ۴ — پیاده‌سازی)
├── feedback/SKILL.md     ← /Feedback (مرحله ۵ — تکرار ↺)
├── doc/SKILL.md          ← /Doc      (مرحله ۶ — نهایی‌سازی)
└── <نام-اسکیل>/           ← هر اسکیل یک پوشه‌ی مستقل
    └── SKILL.md
```

**گردش‌کار VCNO (ترتیب اجرا):** `/init → /check → /PRD → /Build → /Feedback ↺ → /Doc`

**قانون طلایی:** هر اسکیل = یک پوشه + یک فایل `SKILL.md`.
نام پوشه‌ها `kebab-case` و **انگلیسی** باشد (مثل: `fix-flaky-tests`).

## 📋 فهرست اسکیل‌ها

| نام اسکیل | دستور | توضیح کوتاه | وضعیت |
|---|---|---|---|
| [`init`](init/SKILL.md) | `/init` | بازرسانی مخزن و ساخت `docs/project.md` + لاگ — قبل از هر تغییر (کد نمی‌نویسد) | ✅ پایدار |
| [`check`](check/SKILL.md) | `/check` | اعتبارسنجی ایده/نیازمندی/MVP/ریسک → `NOT READY \| READY WITH WARNINGS \| READY FOR PRD` (کد نمی‌نویسد) | ✅ پایدار |
| [`prd`](prd/SKILL.md) | `/PRD` | blueprint آماده‌ی پیاده‌سازی → `DRAFT \| NEEDS CLARIFICATION \| READY FOR BUILD` (کد نمی‌نویسد) | ✅ پایدار |
| [`build`](build/SKILL.md) | `/Build` | پیاده‌سازی تدریجی PRD + تست + checkpoint → `COMPLETE \| PARTIAL \| BLOCKED` | ✅ پایدار |
| [`feedback`](feedback/SKILL.md) | `/Feedback` | بازخورد → آیتم‌های FB-NNN با ریشه‌یابی/تست/وضعیت (حلقه ↺) | ✅ پایدار |
| [`doc`](doc/SKILL.md) | `/Doc` | هم‌راستاسازی داکس با واقعیت → `DOCUMENTED … \| BLOCKED` (فقط داکس) | ✅ پایدار |

## ✍️ چطور اسکیل جدید بسازم؟

1. کپی از الگو:
   ```bash
   cp -r skills/_template skills/<نام-انگلیسی-اسکیل>
   ```
2. فایل `SKILL.md` را باز کن و همه‌ی بخش‌های `...` را پر کن.
3. نام و توضیح را در جدول بالا ثبت کن.
4. به ایجنت بگو از `skills/<نام-اسکیل>` استفاده کند.

## 🤖 نکته برای ایجنت‌ها

- اسکیل‌ها را **دقیقاً طبق مراحل داخل `SKILL.md`** اجرا کن؛ اگر تضادی با کد دیدی، اول به کاربر اعلام کن.
- اگر ایجنت فقط مسیر خاص خودش را می‌خواند، از شیم‌های آماده استفاده کن (همه‌ی ۶ اسکیل این‌طوری‌اند):
  - Claude Code → `.claude/skills/<نام-اسکیل>/SKILL.md` برای هر ۶ اسکیل
  - Copilot → `.github/copilot-instructions.md`
  - Gemini CLI → `GEMINI.md` — Windsurf → `.windsurfrules` — همه به `AGENTS.md` اشاره می‌کنند
- **منبع واحد حقیقت همیشه `skills/<نام>/SKILL.md` است**؛ شیم فقط اشاره می‌کنند، محتوا را کپی نکنید.
- اگر اسکیلی پیدا نشد، **از روی الگو** بساز، نه از حافظه.
